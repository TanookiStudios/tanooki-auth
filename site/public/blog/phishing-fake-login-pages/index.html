Phishing and fake login pages: how to spot them

November 2, 2026

Phishing is a message that pretends to be from a company you trust, to get you to hand over a password, a code or money. The most common trick is a link to a fake login page that looks exactly like the real one.

How a fake login page steals a code

CISA describes the pattern: an email sends you to a copy of a real sign-in page. You type your username, your password and the six-digit code from your authenticator. The page passes all three to the attacker, who signs in as you right away. Two-factor codes help a lot, but they can’t tell a real page from a fake one. You have to.

Warning signs

The FTC and CISA list the same red flags (FTC, CISA):

  • Urgency. “Your account will be closed today.” “Unusual sign-in detected.”
  • A request for personal details, payment information or a code.
  • Links and sender addresses that are slightly off, or shortened links that hide where they go.
  • CISA adds that good spelling and grammar no longer prove a message is real, because scammers use AI tools now.

What to do instead

  • Don’t use the link or phone number in the message. Go to the website by typing its address or using your own bookmark, or call a number you already know.
  • Never read a code to anyone. No real company calls you to ask for one.
  • Let your tools check the address. A password manager won’t fill a password on the wrong site, and Tanooki Auth’s browser extension only fills a code on the exact website that account was saved for. If it won’t fill, stop and look at the address bar.

Report it

The FTC suggests forwarding phishing emails to reportphishing@apwg.org, forwarding scam texts to 7726, and reporting it at ReportFraud.ftc.gov.
