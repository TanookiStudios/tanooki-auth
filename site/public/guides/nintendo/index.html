Turn on two-factor for Nintendo

Use an authenticator app like Tanooki Auth for your Nintendo account at nintendo.com.

  1. Sign in to your Nintendo Account on the web and open Sign-in and security settings
  2. Open 2-Step Verification and start the setup
  3. Scan the QR code with Tanooki Auth (tap +, then Scan QR)
  4. Type the 6-digit code from Tanooki Auth to finish
  5. Save the recovery codes. In Tanooki Auth you can store them in the account's Recovery codes

Good to know: Nintendo only tests Google Authenticator, but its codes follow the standard, so Tanooki Auth should also work. Child accounts can't use it.

Source: Nintendo’s help page

Checked October 30, 2026. Websites change their menus often; if a step looks different, the help page above has the latest.
