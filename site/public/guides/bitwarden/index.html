Turn on two-factor for Bitwarden

Use an authenticator app like Tanooki Auth for your Bitwarden account at bitwarden.com.

  1. Log in to the Bitwarden web app
  2. Go to Settings, then Security, then Two-step login
  3. Find Authenticator App and click Manage, then enter your master password
  4. Scan the QR code with Tanooki Auth (tap +, then Scan QR)
  5. Type the 6-digit code from Tanooki Auth to finish
  6. Save the recovery codes. In Tanooki Auth you can store them in the account's Recovery codes

Good to know: Bitwarden also shows a recovery code on the Two-step login screen; save it right away. Don't store this code in Bitwarden itself.

Open Bitwarden’s settings Source: Bitwarden’s help page

Checked October 30, 2026. Websites change their menus often; if a step looks different, the help page above has the latest.
